# GEOFlux

**Real-Time Global Event Intelligence Stream**

GEOFlux is a simulated distributed sensor network built to explore modern real-time data engineering technologies.

Virtual sensors continuously generate geographically distributed measurements and publish them to Apache Kafka. The system is being developed incrementally to explore event streaming, partitioning, consumer groups, event-time processing, stream analytics, and observability.

## Current Architecture

Virtual Sensors → Kafka Producer → `sensor.raw` → Kafka Consumer

## Current Features

- Apache Kafka running in KRaft mode
- Six-partition `sensor.raw` topic
- Python Kafka producer
- Simulated weather, seismic, and air-quality sensors
- Geographic sensor metadata
- Sensor ID used as Kafka message key
- Per-sensor partition affinity
- Kafka consumer group
- Continuous real-time event ingestion

## Current Sensor Network

| Location | Sensor | Type |
|---|---|---|
| Bengaluru | BLR-WEATHER-001 | Weather |
| Tokyo | TOK-SEISMIC-001 | Seismic |
| London | LON-AIR-001 | Air Quality |

## Kafka Partitioning

Events are keyed by `sensor_id`.

This preserves ordering for measurements generated by an individual sensor while allowing different sensors to be distributed across Kafka partitions for parallel processing.
